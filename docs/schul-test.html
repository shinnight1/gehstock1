Schultest

Findet heraus, warum das Hideout im Schul-WLAN nicht aufgeht - und welche Adresse stattdessen durchkommt.

So benutzen

Diese Datei vorher zu Hause auf das iPad laden (Dateien-App, AirDrop oder OneDrive). Sie selbst braucht kein Netz. In der Schule oeffnen, ins Schul-WLAN gehen, auf Test starten tippen - und danach unbedingt noch den zweiten Test weiter unten machen.

    Ergebnis

    Zweiter Test: die Sperrseite lesen

    Diese Links nacheinander antippen. Ist eine Adresse gesperrt, zeigt der Schulfilter fast immer eine eigene Seite mit seinem Namen und dem Grund ("Kategorie: Spiele", "Web Hosting", "Proxy Avoidance"). Genau dieser Text entscheidet, was hilft - abschreiben oder abfotografieren.
